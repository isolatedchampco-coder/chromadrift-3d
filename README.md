# CHROMADRIFT // 3D Prism Overdrive

A high-resolution WebGL2 3D chromatic hover-craft and kinetic arena action game built with Three.js, custom GLSL shaders, ACES Filmic post-processing bloom, and a reactive Web Audio synthesizer — zero credentials required.

## Quick Start

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (default `http://localhost:5173/`).

## Multi-Key Flight & Combat Controls

- **Flight & Speed**: `W` / `↑` (Afterburner Boost), `S` / `↓` (Precision Air-Brake), `A` / `D` or `←` / `→` (Banked Lateral Carve)
- **Chromatic Frequency Shift**: `Q` / `1` (**Cyan ◆**), `E` / `2` (**Magenta ▲**), `R` / `3` (**Gold ◉**)
- **Vertical & Dash Maneuvers**: `Space` (Jump, Double-Surge, Hold to Glide), `Shift` (Barrel Roll Phase Dash), `C` / `Ctrl` (Magnetic Dive Slam)
- **Combat & Overdrive**: `F` / `J` / `Enter` / `Click` (Twin Plasma Cannons), `X` / `G` (Prismatic Rainbow Nova at 100%)
- **Camera, Audio & Visuals**: `V` / `Tab` (Cycle 4 Camera Rigs), `M` (Toggle Synth Audio), `P` / `Esc` (Settings: Render Resolution `1.0x–2.5x`, Object & Scene Brightness, Bloom Glow, and Color Spectrum Themes)
